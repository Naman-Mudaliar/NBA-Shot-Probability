NBA Shot Probability (xFG%)

Training data & model

The model is shooter-blind: it only sees the shot (location, type, game situation) and the opponent's defense from earlier games. It trained on the early seasons, then walked forward week by week, predicting each week before learning from it. Every xFG% on this page is one of those pre-shot predictions.

xFG outliers

Shot quality = average xFG% of the shots a player takes. Shot-making = actual FG% minus xFG%. Because the model never sees the shooter, the gap is the player's own skill (or luck). z = makes over expected divided by the binomial standard error, so |z| > 2 is unlikely to be luck alone.
